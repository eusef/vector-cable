# Setup guides for the bridge

Drafts of the VectorCable guides that ship on the VectorBridge card. The bridge serves its
`DOCS/*.md` at `/docs/`, so these go into the vector-bridge repo's `DOCS/` by pull request
(BRIDGE reviews). Keep them in step with `vectorcable setup <app>` and the Setup tab.
Neutral wording: no maintainer name, no home address, no bench station details.
